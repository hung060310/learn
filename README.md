# SystemNinfl

A minimal SwiftUI iOS app that displays **systemninfl** on its main screen.

## Run on iOS

1. Open `SystemNinfl.xcodeproj` in Xcode 14 or later.
2. Select an iPhone simulator or a connected iPhone.
3. Press **Build and Run**.

## Project files

- `SystemNinfl.xcodeproj/` — Xcode project.
- `SystemNinfl.xcodeproj/App.swift` — App entry point.
- `SystemNinfl.xcodeproj/ContentView.swift` — Main screen content.
- `SystemNinfl.xcodeproj/Info.plist` — iOS application metadata.

The app targets iOS 17.0 and uses only the SwiftUI framework.
